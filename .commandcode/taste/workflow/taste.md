# Workflow Preferences

- Frequently asks to "commit & push" after units of work; wants changes committed and pushed to the git remote regularly, not left uncommitted. Confidence: 0.9
- For large changes, asks for a proper plan up front with high effort ("Make proper plan using high effort") before implementation begins. Confidence: 0.7
- Wants the app run on an emulator to see results visually ("Run the emulator"), and shares screenshots of running screens as feedback/verification. Confidence: 0.65
- After a plan is implemented, asks to verify the implementation against the plan file and report any inconsistencies, gaps, or needed improvements concisely ("verify the implementation of the plan ... share a concise report"). Confidence: 0.6
- Wants reports shared as markdown files written into the project root ("share the report as markdown"), not just pasted in chat. Confidence: 0.6
